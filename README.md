# 🌱 KindConnect
### Connect Through Kindness, Change Lives.

KindConnect is a community-driven social development events platform that connects people through volunteering, kindness, and meaningful community activities.

The platform empowers users to create social service events, discover upcoming initiatives, join community activities, and make a positive impact on society.

Our mission is simple: bring people together to build stronger, kinder, and more connected communities.

## ✨ Key Features

- **User Authentication:** Secure registration and login using Better Auth.
- **Community Event Creation:** Authenticated users can create social development events with titles, descriptions, categories, images, locations, and event dates.
- **Upcoming Events:** Discover community events dynamically from the database.
- **Event Details:** Explore complete information about individual community events.
- **Join Events:** Logged-in users can join events and participate in social initiatives.
- **Joined Events:** View events joined by the authenticated user.
- **Event Management:** Users can manage, update, and delete their own created events.
- **Protected Routes:** Restrict private pages and operations to authenticated users.
- **Responsive Design:** Optimized experience across desktop, tablet, and mobile devices.
- **Dark/Light Theme:** Customize the application appearance with theme switching.

## 📸 Application Overview

KindConnect provides a community-focused experience through different application sections:

1. **Home:** Introduction, platform features, and recent upcoming events.
2. **Upcoming Events:** Browse all available community events.
3. **Create Event:** Create new social development events.
4. **Event Details:** View event information and join activities.
5. **Joined Events:** Track joined community activities.
6. **Manage Events:** Update or delete events created by the logged-in user.
7. **Authentication:** Register and log in securely.

## ⚙️ Installation & Setup

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the Client Repository

```bash
git clone https://github.com/arman2k2023/KindConnect-Client.git
```

### 2. Navigate to the Project

```bash
cd KindConnect-Client
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env.local` file in the project root.

Add the environment variables required by the client configuration, including the backend API URL and Better Auth configuration where applicable.

Use the exact variable names defined in the project source code.

### 5. Start Development Server

```bash
npm run dev
```

Open your browser:

http://localhost:3000

## 🔐 Authentication & Security

KindConnect uses Better Auth for authentication and session management.

The application includes:

- Email and password authentication.
- User registration and login.
- Session-based authentication.
- Protected application routes.
- Secure communication with backend APIs.
- JWT-based authorization where required.
